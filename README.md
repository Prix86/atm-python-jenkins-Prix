# ATM Python Jenkins Demo

## Descripción

Este proyecto consiste en una simulación de un Cajero Automático (ATM) desarrollada en Python.

El objetivo del proyecto es demostrar la implementación de un proceso de Integración Continua (CI) utilizando:

- Python
- Git
- GitHub
- Jenkins
- AWS Academy

## Funcionalidades

- Consulta de saldo.
- Depósito de dinero.
- Retiro de dinero.
- Validación de saldo insuficiente.
- Validación de montos negativos.

## Tecnologías

- Python 3
- Jenkins
- Git
- GitHub
- AWS EC2
